# PPT 美化检查清单

## 1. 30 秒分诊

拿到一页 PPT，先做四个测试：

| 测试 | 做法 | 不合格信号 |
|---|---|---|
| 标题测试 | 遮住正文，只读标题 | 标题是“业务组合分析”“市场预测”这类栏目名 |
| 眯眼测试 | 退后 2 米/缩小到 25% | 看不出主视觉；所有元素一样重 |
| 灰度测试 | 转黑白/灰度打印 | 重点消失；层级靠颜色硬撑 |
| 数据测试 | 只看图/表 | 找不到单位、来源、样本量；数字对不上 |

四项里有两项不合格，不要先换色，先重做结构。

---

## 2. 12 项诊断评分卡

每项 0–2 分：

- **0** = 明显不合格，需要重做。
- **1** = 能做但费劲，需要优化。
- **2** = 清楚、可复用。

| # | 维度 | 0 分的样子 | 2 分的样子 |
|---|---|---|---|
| 1 | 主张 | 没有结论/标题是栏目名 | 标题是一句可争论的判断 |
| 2 | 叙事 | 信息平铺，无先后 | 3–4 个模块形成因果/对比/流程 |
| 3 | 层级 | 所有元素差不多大 | 标题—证据—注释三层清楚 |
| 4 | 网格 | 元素自由摆放、边距不一 | 对齐 12 栏、卡片等高 |
| 5 | 密度 | 一页 8 个以上模块/长段落 | 一页 3–4 块，每块≤2 行 |
| 6 | 色彩 | 多色、无含义、低对比 | 3 色相以内，颜色有语义 |
| 7 | 字体 | 多字族/字号乱/太小 | ≤2 字族、3 字重、正文≥10 pt |
| 8 | 图表 | 3D/无标签/图例混乱 | 图型正确、直接标注、单点高亮 |
| 9 | 表格 | 大段文字、无结论列 | ≤4×6、数字右对齐、有 So what |
| 10 | 图像 | 装饰性 stock photo/太小 | 提供证据、裁切一致、有来源 |
| 11 | 一致性 | 每页像不同人做的 | 母版/色板/页脚/图表风格统一 |
| 12 | 准确性 | 数字/单位/口径矛盾 | 可追溯、有来源、有限制条件 |

**总分解释：**

- **0–8**：需要重构，不是美化。
- **9–16**：先改结构和图表，再做视觉统一。
- **17–20**：做一致性、标注、可读性精修。
- **21–24**：可以进入交付检查。

### 标题改写练习

把下面的“栏目名”改成“行动标题”：

| 栏目名 | 行动标题 |

## 4. 图表检查清单

### 选图

- [ ] 比较类别：横向条形图，降序。
- [ ] 时间趋势：折线/柱状；不要用饼图。
- [ ] 构成：堆叠柱/100% 堆叠；扇区≤5 才考虑饼图。
- [ ] 相关：散点图；不要用双轴硬凑。
- [ ] 流程：箭头/chevron/环形；不要用柱状图。
- [ ] 地理：地图；不要用四个文字框代替。
- [ ] 分布：直方图/箱线图；不要用折线。

### 清理

- [ ] 去掉 3D、阴影、渐变、粗边框。
- [ ] 去掉无意义网格线；保留必要基线。
- [ ] 柱状图从 0 开始；折线图标注范围。
- [ ] 系列≤4 时优先直接标注，不用图例。
- [ ] 单位、口径、样本量、来源齐全。
- [ ] 图表标题/小标题说“结论”，不是“图表类型”。

### 强调

- [ ] 只高亮一个 series/区间/数据点。
- [ ] 高亮用酒红；其余用灰/浅豆绿。
- [ ] 关键拐点加一句注释（≤2 行）。
- [ ] 注释靠近数据，不要放页脚。
- [ ] 图表和标题里的数字对得上。

### 常见错误

- [ ] 饼图切太多块。
- [ ] 柱状图截断基线，夸大差异。
- [ ] 双轴图制造虚假相关。
- [ ] 堆叠柱没有图例/标签，受众不知道哪层是哪层。
- [ ] 折线图每个点都标数，变成“数字项链”。
- [ ] 用面积图表达不可累加的比例。

## 5. 文字检查清单

### 删

- [ ] 删掉“进行了/实现了/相关的/方面的/一定程度上”等虚词。
- [ ] 删掉没有数据支撑的形容词（显著/大幅/领先/优质）。
- [ ] 删掉重复句、同义反复、背景套话。
- [ ] 删掉“Here you can write”“Lorem ipsum”“XXX”等占位符。

### 改

- [ ] 标题：主语 + 判断 + 数字/影响。
- [ ] 小标题：动词开头，≤12 字。
- [ ] 正文：每条≤1 行；每段≤2 行。
- [ ] 数字：保留单位、口径、时间范围；不要只写“增长 20%”。
- [ ] 术语：全篇统一（如“门店/终端”“营收/收入”）。
- [ ] 中英文：统一大小写、空格、标点；不要中英混排无空格。

### 查

- [ ] 拼写/语法（尤其下排案例里的 `withdifferent`、`seniorcities`）。
- [ ] 数字与图表/表格一致。
- [ ] 来源/注释/版权。
- [ ] 没有把“预测”写成“事实”。
- [ ] 没有隐藏不利数据/限制条件。

## 6. 版式检查清单

- [ ] 16:9；页边距一致。
- [ ] 12 栏网格；所有模块对齐。
- [ ] 一页 3–4 个主模块；最多 5 个。
- [ ] 一个视觉中心；主图占 50–70% 视觉重量。
- [ ] 标题左对齐；正文左对齐；数字右对齐。
- [ ] 卡片等高、等宽、等内边距。
- [ ] 模块间距 ≥0.25 in；卡片内边距 0.12–0.18 in。
- [ ] 没有“第四层强调”；强调不超过 2 种手段（颜色+字号/图标+底色）。
- [ ] 页脚/页码/Logo 位置统一。
- [ ] 没有元素溢出页面/压住文字。

## 7. 交付前检查

### 内容

- [ ] 每页一个结论；结论有证据。
- [ ] 故事线连贯：上一页的结论是下一页的前提。
- [ ] 数字/单位/口径/时间范围一致。
- [ ] 来源、样本量、注释齐全。
- [ ] 没有伪造/猜测/夸大。
- [ ] 有“所以呢/下一步”。

### 视觉

- [ ] 3 秒测试通过。
- [ ] 眯眼测试通过。
- [ ] 灰度测试通过。
- [ ] 投影测试：10 pt 可读；对比度足够。
- [ ] 颜色不是唯一编码方式。
- [ ] 图片清晰、裁切一致、有来源。
- [ ] 图表可直接读，不需要演讲者解释。

### 技术

- [ ] 字体已嵌入/转曲（按交付要求）。
- [ ] 图片压缩后仍清晰。
- [ ] PDF 无溢出/错位/字体替换。
- [ ] 可编辑源文件保留。
- [ ] 图表数据可追溯。
- [ ] 重要图片/图表有 alt text。
- [ ] 文件命名规范：`项目_版本_日期.pptx`。

## 8. 常见 red flags

看到以下信号，先停下来重想，不要继续加样式：

- 标题是名词短语，不是句子。
- 一页有 5 个以上同等大小的框。
- 图表没有数据标签，但有图例。
- 表格单元格里出现“；”和“同时”。
- 同一页出现 4 种以上颜色。
- 重点靠“红色+加粗+放大+阴影”四件套。
- 图标比文字多。
- 图片只是“看起来热闹”。
- 页脚没有来源，但正文有精确数字。
- 下排比上排更花，但结论更模糊。

## 9. 验收标准（给客户/评审用）

一份合格的美化稿应满足：

1. **可复述**：任选一页，受众能在 10 秒内说出结论。
2. **可追溯**：每个关键数字都有来源/口径。
3. **可扫读**：标题、模块、图表三层结构清楚。
4. **可复用**：同类页面能套用同一版式，不需要每次重画。
5. **可交付**：PDF/源文件/字体/图片/备注齐全。
6. **不误导**：没有为了视觉冲击截断基线、隐藏样本量、夸大差异。

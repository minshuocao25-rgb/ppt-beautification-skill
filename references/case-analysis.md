# 11 组 before/after 逐页拆解

> 上排是“屎盆子”（灰度草稿），下排是“镶金边”（美化版）。  
> 每一组都按“原稿问题 → 采用的设计 → 关键操作 → 可复用结论”拆解。  
> 注意：下排也不是完美无缺，最后一节单列了仍然存在的硬伤。

## 01 区域扩张：灰色地图 → 战略地图

**原稿**

- 一张浅灰中国地图，四个区域用虚线圆圈和四段悬空文字标注。
- 左下两段“高优先级/低优先级”文字；右下孤立的灰色堆叠柱，图例挤在柱旁。
- 没有标题层级，地图不承载数据，读者不知道“已进入/未进入”的差别。

**采用的设计**

- **地图成为数据层**：已进入省份深酒红，未进入省份灰粉，目标城市用星标，区域用编号锚点连接文字。
- **四区卡片化**：Midwest / Southern / Northern / Core 四组信息对齐在地图四角，优先级用实心/空心星表达。
- **右下从“图”升级为“预测 + 决策”**：堆叠柱加图例、数据标签和标题；下方增加直营/加盟/子加盟的决策矩阵。
- **底部优先级分组**：高/低优先级用浅灰圆角条 + 小地图缩略图 + 一句策略。

**关键操作**

- 地图按类别填色；加星标城市；区域编号用酒红圆形。
- 堆叠柱：统一色板、加图例、加数据标签、拉开柱间距、去掉多余边框。
- 四区文字：统一“区域名—中心—状态—优先级”四行结构，左对齐。
- 决策矩阵：三行（直营/主加盟/子加盟）× 四列（成本/控制/灵活/可及），用红色圆点表示强弱。
- 页脚/Logo/标题统一。

**可复用结论**

> 地图不是背景，是数据编码；决策表要跟证据放在同一页，而不是让受众自己推。

## 02 3S 战略：三栏灰文 → 三列系统图

**原稿**

- 顶部一行“3S: Standardization + Smart digitalization → Scale economy”。
- 下方三栏全是灰色文本框：左栏一张普通表格，中栏散落着 store app / transport / purchasing 等词，右栏三个灰色收益框。
- 三栏之间没有箭头，读者看不出“3S”之间如何联动。

**采用的设计**

- **顶部做成 3 段式策略带**：三个色块/chevron 明确“标准化 + 智能数字化 → 规模经济”。
- **左栏流程化**：质量分级表 + Plant/Test/Pack/Trans 四条纵向能力条，配图标和一句规则。
- **中栏图形化**：用循环图把 criteria / store app / store age / transport / purchasing / production 串成闭环，外圈加四个 callout。
- **右栏收益编号化**：1 Integration / 2 Utilization / 3 Cost-saving，配 33%/70%/100% 的关键数字和一句解释。
- **底部金句框**：把“SD2 可把物流成本占比降到 10% 以下”做成引用块，形成收口。

**关键操作**

- 用 chevron/箭头建立三栏关系；每栏加小标题。
- 左侧四个流程行：竖向标签 + 图标 + 一条规则，避免大段文字。
- 中栏用圆形箭头/循环图；中心放一个简洁图标，不要放复杂插画。
- 右侧数字用大字号，解释控制在 2 行。
- 全篇统一青绿/酒红/米白；灰色只做辅助。

**可复用结论**

> 当页面是“三个并列主题”时，先问它们有没有先后/因果/循环关系；有，就画出来。

## 03 碳素饮料预测：两张表 + 灰柱 → 三幕预测链

**原稿**

- 左侧两张 CAGR 表，表头/口径重复，数字有互相矛盾的风险。
- 右侧一张灰色柱状图，无数据标签、无注释、无结论。
- 标题虽然有“8.4 billion / 2026”，但正文没有形成“假设—产品—收入”的因果链。

**采用的设计**

- **三幕结构**：Key Assumptions（左）→ Product Rev. Forecast（中）→ NF Revenue Forecast（右），用箭头/栏头形成从左到右的推理链。
- **表格合并去重**：只保留一套 Project/CAGR 口径，负值用酒红标出，补充收入口径脚注（三项收入相加）。
- **散点/趋势图讲产品**：每个年份标数字（8/29/36/46/61/84），加两条注释“更多高价产品上市”“平均价格上行”。
- **收入图讲结果**：柱状图突出 2026–2027，直接标数，统一单位“RMB 100 Million”。
- **底部一句 takeaway**：Non-cola carbonates is promising in next 5 years.

**关键操作**

- 删除重复表；统一单位、年份范围、CAGR 区间。
- 散点图加数据标签、趋势线/箭头、2 条注释；不要只留坐标轴。
- 收入图把“历史/预测”用深浅色区分；最后两年用酒红强调。
- 每张图上方加小标题；图下加一句“所以呢”。
- 页脚放来源/口径。

**可复用结论**

> 如果受众要在脑子里做算术，这页就没完成；把“假设→产品→收入”拆成三幕，让图自己讲故事。

## 04 业务组合选择：密集评分表 → 人群先行的卡片组

**原稿**

- 一张大表：Jewelries / Fashion / Cosmetics × Price / Sales Volume / Cost Structure / Selection。
- 每格都是长段落 + 分数（2.5/3、1/3 等），阅读负担极高。
- 没有“谁在买、为什么买”的上下文，直接跳到“选哪个”。

**采用的设计**

- **先人群，后业务**：上方三张图——城市等级分布、年龄分布、购买奢侈品的 Top 5 理由；下方才是业务组合选择。
- **表格变卡片**：三个业务各一张卡，配图标（宝石/衣服/香水瓶）、价格/销量/结构三行短评、右侧总分徽章和表情符号。
- **评分可视化**：4.6 / 5.3 / 5.9 的分数用大字号 + 表情，形成快速排序。
- **文案压缩**：每格从一段话压到 2–3 行，只留“高/低/有限/强”的判断。

**关键操作**

- 顶部三张 100% 堆叠条/横向条形图，统一图例和年份。
- 下方三列卡片：等高、等宽、图标统一线宽；每张卡内部行结构一致。
- 分数放在右上角，形成“扫描列”；不要藏在段落里。
- 用酒红/灰粉区分“高潜力/次潜力”，但保留文字判断。

**可复用结论**

> 选择类页面要先给“选择标准”和“受众证据”，再给“选项打分”；大表格通常应拆成卡片。

## 05 养老社区：小照片 + 灰表 → 人物与证据

**原稿**

- 左侧购买标准灰色条形图；右侧竞品对比表，全是小字段落。
- 下方三张邮票大小的照片 + A/C/B 三段客户档案，字号小、信息挤。
- 图片没有承担证据作用，只是“有张图”。

**采用的设计**

- **人物卡放大**：三行客户档案，圆形头像 + 姓名/年龄/净值/原话，信息分层。
- **雷达图做画像**：Age / Net Worth 两个维度，当前目标客户 vs 未来潜在客户，用绿色多边形对比。
- **购买标准条形图**：51/35/27 直接标数，Top 3 用括号/标注收口。
- **竞品对比图片化**：Taikang Community vs Senior Living L'amore，每个能力维度用一张社区场景图 + 一句短评，替代纯文字表格。

**关键操作**

- 人像统一裁切为圆形/同比例；加姓名、年龄、净值、引语四行。
- 雷达图只放 2–3 个可比维度；轴标签清楚；不要用它做排序。
- 对比表：行标签在左，两个竞品在右；每个单元格用“图片 + 一句判断”，不要段落。
- 购买标准图：横向条形、降序、直接标签、Top 3 标注。

**可复用结论**

> 当论点是“客户是谁/为什么选我们”时，人脸、原话、场景图就是证据；图片要大，文字要短。

## 06 企业生命周期：七个灰框 → S 曲线 + 双轨

**原稿**

- 七个等高灰色圆角框横排，每框一段密集说明；顶部一条年份带。
- 阶段之间没有“加速/成熟/衰退”的势能，七个框看起来同等重要。
- 文字小而密，年份与阶段名不对齐。

**采用的设计**

- **S 曲线主视觉**：一条绿色上升曲线贯穿页面，表达“初创—成长—成熟—转型”的势能。
- **四阶段分组**：把七个 sub-stage 合并为 Startup / Growth / Maturity / Transformation 四个 phase，用竖向虚线分隔。
- **双轨对照**：China 轨道在上、Global 轨道在下，同一时间轴对比。
- **阶段卡颜色化**：酒红阶段卡 + 青绿阶段带，年份用黑底/白底小块。
- **流程箭头**：Agile innovation / Ecological cooperation / Talent-driven culture 三条斜向箭头，补充“怎么演化”。

**关键操作**

- 用自由曲线/曲线形状画 S 曲线；阶段带用半透明色块，不要遮住文字。
- 七个阶段卡沿曲线下方排布，保持同一基线。
- 年份用等距刻度；阶段名与年份对齐。
- 每条轨道只保留关键词，详细解释移到备注/附录。

**可复用结论**

> 生命周期本质是“曲线 + 阶段”，不是“七个同样大的盒子”；先分组，再对齐，再减字。

## 07 模板页：一张孤图 → 四联模板墙

**原稿**

- 左侧一张灰色堆叠柱（2022/2030/2040），右侧四列“Here you can write...”占位文字。
- 没有标题、没有图例、没有数据标签；页面像未完成的草稿。

**采用的设计**

- **四联模板墙**：同一组数据重复四次，展示四种版式/强调方式；每列“说明 + 图 + 两条 bullet”。
- **统一图表语言**：同样的系列色、数据标签、图例、坐标轴、柱间距。
- **标题/页脚系统**：顶部大标题 + Logo，底部一句说明，形成模板页的完整结构。
- **重复中的差异**：只改变强调的 series/布局，不改变视觉规则。

**关键操作**

- 复制图表组 → `Align > Distribute Horizontally`；四列等宽。
- 统一图表字体/颜色/标签；用 `Format Painter`。
- 每列上方一句“使用场景”，下方两条“写作提示”。
- 保留占位符时，用统一占位文案，避免“Lorem ipsum”式混乱。

**可复用结论**

> 如果内容本身就是“模板/版式方案”，就展示一个系统，而不是一张孤立的图；重复必须统一。

## 08 金融科技时间线：灰色斜线 → 增长曲线

**原稿**

- 灰色背景 + 一条斜向上的黑线，2015–2025 每个年份拉一条竖线 + 一段密集小字。
- 信息量过大，重点事件被淹没；没有标题，读者不知道“这条线说明什么”。

**采用的设计**

- **增长曲线/山形面积**：青绿色折线 + 浅色面积，表达“组合在扩张”。
- **选择性标注**：只给关键节点（牌照申请、ETP 上市、合作、FATF 规则）写解释；其他年份只留刻度。
- **大标题**：An expanding portfolio of high-value options；副标题交代背景。
- **强对比**：浅灰绿背景 + 深青绿曲线 + 大号年份；弱化非重点文字。

**关键操作**

- 用折线/面积图替代手绘斜线；节点用圆点/竖线标记。
- 只保留 3–5 个 callout；其余事件移到附录/备注。
- 年份字号大于事件说明；事件说明不超过 2 行。
- 背景降低饱和度，让曲线成为视觉中心。

**可复用结论**

> 时间线不是“每个事件都要说话”；用曲线表达势能，用少量标注表达转折。

## 09 设计流程：断开的柱 + 四列字 → 环形四步

**原稿**

- 上方一张无 x 轴标签的灰色柱状图（19/5/50/40/45/6/80/30）。
- 下方四列 01–04 文字，介绍/发现/设计/交付；图和文字没有关系。
- 读者看不出这是流程，也看不出每步要多久。

**采用的设计**

- **环形流程**：中心花瓣/环形图，四周 01 Define / 02 Discover / 03 Design / 04 Deliver 四步，箭头连接成闭环。
- **步骤卡**：每步“编号 + 动词 + 3 条交付物 + 时间”（1 周/2 周/1.5 周/0.5 周）。
- **中心图**：把百分比变成花瓣长度/面积，形成视觉锚点；不再用孤立柱状图。
- **统一色板**：青绿/深灰花瓣，酒红只做少量强调。

**关键操作**

- 用环形/花瓣形状围绕中心排布；每步用弧线箭头连接。
- 步骤编号大字号；动词开头；时间放在最后一行。
- 中心图不要放复杂插画；一个抽象几何/进度环即可。
- 四步卡片等距、等宽；文字左对齐。

**可复用结论**

> 如果信息是流程，就画流程；不要用“图 + 四列字”让受众自己拼关系。

## 10 无糖市场：无标签堆叠柱 → 增长拆解

**原稿**

- 一张灰色堆叠柱（2022/2030/2040），没有图例、没有数据标签、没有单位。
- 只有“量”的变化，没有解释“为什么涨”。

**采用的设计**

- **主图加标注**：三个年份、三层 series、直接标数；+9% 增长箭头；柱旁加 CAGR 小表；假设表中的负值用酒红标出。
- **右侧 driver 面板**：Non-Sugar Market vs With-Sugar Market 两栏，分别列价格、渗透率、客群等驱动，配 3–5% / 30–35% / -1% 等数字。
- **Highlights 收口**：3 条“所以呢”，把图变成结论。
- **底部一句 takeaway**：Non-cola carbonates is promising in next 5 years.

**关键操作**

- 堆叠柱：统一色板、加图例、加数据标签、标单位；突出增长最快的一层。
- 加箭头/括号标注增长幅度；不要只靠视觉高度。
- 右侧两栏 driver：标签 + 数字 + 一句解释；每栏不超过 4 条。
- 底部 highlight 框用浅豆绿底，形成“结论区”。

**可复用结论**

> 图表回答“发生了什么”，driver 面板回答“为什么”，highlight 回答“所以呢”；三者齐全，图表才变成洞察。

## 11 文字版式：居中大标题 + 三段字 → 三条横带

**原稿**

- 居中大标题 + 三大段 A/B/C 重复占位文字；没有视觉结构，阅读顺序靠猜。
- 页面大量空白，但空白没有用于分组。

**采用的设计**

- **三条横带**：A/B/C 三个模块，每条“超大字母 + 青绿左边框 + 加粗小标题 + 两栏正文 + 右侧小图”。
- **信息分层**：大字母做导航，小标题做主张，正文做解释，小图做证据。
- **强调框**：用方括号/浅色底把“Important information is written here”做成视觉锚点。
- **重复中的统一**：三条横带结构完全一致，形成节奏。

**关键操作**

- 三条圆角矩形横带等高；左侧 0.08–0.12 in 青绿边框。
- 大字母 40–54 pt，颜色浅灰/青绿，不抢正文。
- 正文分两栏，每栏 ≤ 3 行；行距 1.2。
- 右侧小图只放一个信息（如 2022 vs 2030 的 7.9→8）；加图例/标签。

**可复用结论**

> 文字多的页面，不是加装饰，而是加“节奏”和“重复模块”；让读者知道从哪里开始、在哪里停。

## 12 共同规律：11 组对照到底变了什么？

### 12.1 五类变化，按重要性排序

1. **信息结构变了**：从“平铺/罗列”变成“主张—证据—含义”的论证链。
2. **视觉层级变了**：从“所有元素差不多大”变成“标题—模块—注释”三层。
3. **信息密度变了**：删掉重复、合并表格、把段落拆成短句/数字/标签。
4. **视觉编码变了**：颜色、地图、曲线、流程、图标开始“编码含义”，而不是装饰。
5. **系统一致性变了**：网格、字体、色板、页脚、图表风格全篇统一。

### 12.2 最值得复用的 8 个动作

1. 把栏目名改成**带数字/判断的行动标题**。
2. 把自由摆放改成**12 栏网格 + 3–4 个模块**。
3. 把大表格拆成**等高卡片 + 评分徽章**。
4. 把默认图表改成**直接标注 + 单点高亮 + 一句注释**。
5. 把“三个并列主题”改成**箭头/循环/流程**。
6. 把“七个灰框”改成**S 曲线 + 阶段分组**。
7. 把“文字堆”改成**横带/卡片 + 图标 + 小图**。
8. 把“单页灵感”沉淀成**母版/模板/色板/图表预设**。

### 12.3 下排仍然存在的硬伤（不要照抄）

美化版仍有明显问题，说明“视觉高级”不等于“内容正确”：

- **拼写/语法**：`withdifferent`、`seniorcities`、`wit, 1/3sugar`、`penetration ratein`、`Bank guaranteeto` 等。
- **占位符残留**：`Here you can write...`、`Content is virtual`、`write here`。
- **内容错位**：第 9 页标题/文案明显来自另一套模板，与设计流程无关。
- **数据口径**：部分表格/图表数字对不齐，CAGR 区间和年份范围需要复核。
- **装饰过度**：部分图片/图标只是“看起来丰富”，没有增加信息。
- **可读性**：个别小字仍低于投影可读尺寸。

**结论：学它的结构、层级、图表标注和系统化，不要学它的文案与数据疏忽。**
